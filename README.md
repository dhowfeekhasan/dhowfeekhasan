## ◈ Research Tracks

```
  Agent Memory & Long-Term Context
  → stateful agents, episodic memory, context compression across sessions

  Efficient Model Adaptation
  → LoRA, QLoRA, RLHF, DPO — domain adaptation without full fine-tuning

  Source-Grounded Research Systems
  → deep research agents with citations, Firecrawl + Exa + Tavily pipelines

  Multimodal Knowledge Architectures
  → unified retrieval across text, tables, charts, and images

  Systematic Prompt Engineering
  → DSPy, structured outputs, evaluation frameworks, self-consistency

  Serverless AI Infrastructure
  → Modal, edge inference, latency-optimized deployment patterns
```
